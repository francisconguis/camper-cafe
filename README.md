## 📌 About the Project

This project focuses on introductory CSS styling, visual layout structuring, and responsive container centering. It simulates a restaurant/cafe menu board set against a themed background image, demonstrating how HTML structure and external CSS rules collaborate to present formatted pricing and menu categories.

## 🛠️ Key Concepts Practiced

* **External Stylesheets:** Linking and structuring rules across separate HTML and CSS files (`index.html` and `style.css`).
* **Background Styling:** Applying full-page tiled background assets (`background-image: url(...)`) from external CDNs.
* **Horizontal Centering:** Centering block-level containers using auto margins (`margin-left: auto; margin-right: auto;`) with percentage-based responsive widths (`width: 80%`).
* **Typography Alignment:** Using `text-align: center` across headings and paragraphs for uniform presentation.
* **Semantic Web Structure:** Organizing items into `<main>`, `<section>`, and `<article>` tags for menu items and pricing pairs.
